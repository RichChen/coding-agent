## 主要分析

保持冻结后的定义，并且只用 r1–r3。d_t 是 B2 与 B0 的解出率之差，解出率是非 `infra_error` 运行里的解出次数除以有效运行数。三次都有效时，这就是 k/3。r4 不进入主要分析，也不拿来补齐缺失的重复。

置换检验和 bootstrap 仍是各 10000 次，种子 20260926。

检测下限写两个数：设计阶段的 2.8×0.35/√N，以及用本次 d_t 样本标准差代替 0.35 之后的 2.8×s/√N。

## 次要分析

分组改为处理前预测会注入至少 1 张卡的题。依据是 harness 的 `docs/sprint/b2-predicted-injection.json`。文件里每道题带 `cards` 或 `card_ids` 列表，或者带 `predicted_cards` 整数。

实际注入至少 1 张卡的题保留，只做一致性核对。两组题应该相同。没有这份预测表时，不把实际注入说成预测。

## 描述性追加，不做检验

漂移：按题比较 B0 r4 的 0/1 和 B0 r1–r3 的解出率，报告平均差和 bootstrap 95% 区间。区间不含 0 时，在主要分析的结论后面标“存在时间漂移”。

敏感性：用 r4 当作同期 B0，计算 B2 的 k/3 减去 r4 的 0/1，只报告平均值。

按 B0 档位（0/3、1–2/3、3/3）列出平均 d_t 时，必须写明：按 B0 结果分组会受回归均值影响，不可作为效应证据。

这些小节的标题都带“描述性，非预注册”。
